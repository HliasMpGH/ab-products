# AB Testing Product Search

A (nearly) single-page application for experimenting with and demonstrating AB testing methodologies by varying product presentation to users.

## Overview

This repository contains a product search application designed specifically for conducting AB testing experiments. It allows administrators to create different presentation variants for search results and analyze user behavior across these variants to determine optimal product display methods.

## Features

## Test Variants

Examples of presentation variables that can be tested:

- Grid vs. list view layouts
- Product information density (minimal vs. detailed)
- Image sizes and quantities
- Price presentation (with/without discounts, positioning)
- Call-to-action button styling and text
- Sort order algorithms
- Featured product highlighting techniques
- Filtering UI implementations
